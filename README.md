# 📚 StudyBuddy AI – Personal Study Assistant Agent

### Learn How Generative AI Models and AI Agents Work — From Scratch

**Developed by: Mahnoor**

StudyBuddy AI is an AI-powered study assistant developed using Python and Google Gemini. It helps students understand educational concepts, interact with AI, and find answers from their own study materials.

The project demonstrates how Large Language Models (LLMs), system instructions, conversational memory, tool calling, and Retrieval-Augmented Generation (RAG) work together to build an AI assistant.

It also provides an interactive web interface where students can ask general questions and upload their study documents.

## 🎯 Project Objectives

- Understand how Generative AI models work.
- Learn the fundamentals of AI agents.
- Explore system instructions and conversational memory.
- Implement tool calling using Python functions.
- Understand Retrieval-Augmented Generation (RAG).
- Build an AI study assistant that answers questions using uploaded documents.

## ✨ Project Highlights

- 🧠 **Google Gemini AI:** Generate intelligent and helpful responses.
- 📝 **System Instructions:** Control the model's role and behavior.
- 💬 **Conversational Memory:** Maintain conversation context.
- 🛠️ **Tool Calling:** Allow an agent to request actions through Python functions.
- 📚 **RAG:** Retrieve relevant information from study materials.
- 📂 **Document Upload:** Upload PDF, TXT, and DOCX files.
- 🔎 **Information Retrieval:** Find relevant text chunks from uploaded documents.
- 🌐 **Web Interface:** Interact with StudyBuddy through Streamlit.

## 🏗️ Project Architecture

The project introduces one new AI concept in each phase.

```text
Phase 1: Basic AI Model
        ↓
Phase 2: Model + System Instructions
        ↓
Phase 3: Model + Instructions + Memory
        ↓
Phase 4: Model + Instructions + Memory + Tools
        ↓
Phase 5: Retrieval-Augmented Generation (RAG)
        ↓
       StudyBuddy AI
```
